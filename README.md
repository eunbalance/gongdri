# 공드리 · 이국적인 언어로 새벽 토크

PC 크롬 안에서 AI가 직접 돌아가는 영어·프랑스어 회화 연습 사이트예요.
서버, API 키, Claude 사용량 없이 무료로 쓸 수 있어요.

## 무엇으로 돌아가나요
- **대화 AI**: WebLLM(Qwen2.5). 처음 한 번 모델을 받으면 브라우저에 저장돼서 다음부터 바로 열려요
- **음성 듣기**: 브라우저에 들어 있는 음성 기능(Web Speech API)
- **마이크 받아쓰기**: 크롬 음성 인식. 영어는 en-US, 프랑스어는 fr-FR로 받아적어요
- **기록**: 이 브라우저(localStorage)에 저장돼요. 노션에는 **「노션용으로 복사」**를 눌러 붙여넣으면 돼요

## 필요한 환경
- [ ] PC용 최신 **크롬** 또는 **엣지**(WebGPU 지원)
- [ ] 그래픽 메모리 여유: 가벼움 약 1.6GB / 보통 약 2.5GB / 고품질 약 5.1GB
- [ ] 첫 실행 때 모델을 받을 인터넷 연결과 저장 공간
- [ ] **https 주소**로 열기(마이크 권한 때문에 필요해요. 아래 배포 방법 중 하나를 쓰면 자동으로 https가 돼요)

> 크롬 음성 인식은 무료지만, 받아쓰기할 때 목소리가 구글 서버로 보내져요.

## 배포 방법 (셋 중 하나, 모두 무료)

### A. Netlify Drop — 가장 쉬움
1. [ ] https://app.netlify.com/drop 접속 후 로그인
2. [ ] 압축을 푼 `gongdri-site` 폴더를 통째로 화면에 끌어다 놓기
3. [ ] 생성된 `https://….netlify.app` 주소를 크롬 북마크에 추가

### B. GitHub Pages
1. [ ] GitHub에서 새 저장소 만들기(예: `gongdri`)
2. [ ] 폴더 안 파일을 모두 업로드(`index.html`, `bg.jpg`, `bg-s.jpg`, `fonts/`)
3. [ ] Settings → Pages → Branch를 `main` / `root`로 저장
4. [ ] 몇 분 뒤 `https://아이디.github.io/gongdri/`로 접속

### C. Vercel
1. [ ] B처럼 GitHub에 올린 뒤 https://vercel.com 에서 그 저장소를 Import
2. [ ] Framework는 **Other**, 빌드 설정 없이 Deploy

## 처음 쓸 때
1. [ ] 사이트를 열고 4단계의 **「AI 미리 받기」**를 눌러 모델 받기(보통 모델 기준 몇 분 걸려요)
2. [ ] 「나에 대해」를 열어 내 소개를 영어로 적어두면 대화가 더 맞춤형이 돼요
3. [ ] 언어·난이도·주제를 고르고 **대화 시작**
4. [ ] 마이크 버튼을 누르고 말하기 → 말을 멈추면 자동으로 보내져요
5. [ ] 끝나면 **완료** → 교정 노트와 퀴즈 확인 → **노션용으로 복사**

## 참고
- 휴대폰에서는 대부분 WebGPU와 메모리가 부족해서 AI가 돌아가지 않아요. PC 전용으로 생각해 주세요
- 작은 모델이라 교정이 Claude만큼 섬세하지는 않아요. 답이 이상하면 **고품질** 모델로 바꿔보세요
- 기록은 브라우저마다 따로 저장돼요. 브라우저 데이터를 지우면 함께 지워져요
